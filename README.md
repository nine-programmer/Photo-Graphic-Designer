# Photo Graphic Designer

สกิลสำหรับออกแบบกราฟิกทับบนภาพถ่าย เช่น โปสต์การ์ด โปสเตอร์ และภาพสำหรับโซเชียลมีเดีย โดยใช้ HTML, CSS และ SVG เพื่อให้ข้อความและลวดลายคมชัด พร้อมรักษาภาพถ่ายต้นฉบับไว้ ไม่ใช้การสร้างภาพใหม่ทับภาพเดิมซึ่งอาจทำให้ใบหน้า ฉาก หรือรายละเอียดในภาพเปลี่ยนไป

## สกิลนี้ช่วยอะไรได้บ้าง

- วิเคราะห์ภาพ ขนาด สี และพื้นที่ว่าง เพื่อเลือกตำแหน่งวางข้อความ
- เสนอแนวทางการออกแบบให้เลือก เช่น มินิมอล วินเทจ โรแมนติก หรือแคมป์ปิ้ง
- ช่วยร่างข้อความภาษาไทยและอังกฤษให้เข้ากับโทนที่ต้องการ
- สร้างกราฟิกด้วย HTML/CSS/SVG และเรนเดอร์ภาพความละเอียดสูง
- ตรวจภาพที่เรนเดอร์แล้ว เพื่อหาปัญหาการอ่าน การตัดบรรทัด และองค์ประกอบทับซ้อน

## วิธีติดตั้งด้วย `npx skills add`

ต้องมี Node.js และ npm ก่อน จากนั้นใช้คำสั่งนี้ โดยแทน `<owner>/<repo>` ด้วยชื่อ GitHub ของ repository ที่เผยแพร่สกิลนี้:

```bash
npx skills add <owner>/<repo> --skill photo-graphic-designer
```

ตัวอย่างรูปแบบคำสั่ง:

```bash
npx skills add your-github-name/your-skills-repo --skill photo-graphic-designer
```

ตัวเลือก `--skill photo-graphic-designer` ใช้ระบุให้ติดตั้งสกิลนี้โดยตรง หาก repository มีหลายสกิล เครื่องมืออาจให้เลือกตำแหน่งหรือ agent ที่ต้องการติดตั้ง ทำตามขั้นตอนที่แสดงบนหน้าจอ แล้วเริ่มเซสชันใหม่หรือโหลด agent ใหม่เพื่อให้สกิลพร้อมใช้งาน

## วิธีใช้งาน

หลังติดตั้งแล้ว ให้แนบหรือระบุภาพที่ต้องการออกแบบ พร้อมบอกจุดประสงค์ ข้อความหรือโทนที่ต้องการ เช่น:

> ช่วยทำโปสต์การ์ดทริปแคมป์ปิ้งจากภาพนี้ โทนอุ่นแบบฟิล์ม ใส่ชื่อสถานที่และวันที่ โดยไม่บังคนในภาพ

ดูรายละเอียด workflow และข้อกำหนดของสกิลได้ที่ [SKILL.md](./SKILL.md)
